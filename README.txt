RPM Docs — исправленный комплект 3.4.1

Распакуйте архив целиком в новую папку. Откройте index.html.
При обновлении хостинга загрузите весь комплект, обязательно заменив index.html. Затем обновите страницу через Ctrl+F5.
Страница использует app-rpm-v34.js и styles-rpm-v34.css. Их имена менять не нужно. Папки assets и vendor также должны находиться рядом с index.html.

RPM Docs — готовая версия

Распакуйте архив целиком и откройте index.html в браузере.
Версия функций: 3.4 — отмена изменений и перенос документа.
Распакуйте в НОВУЮ папку и открывайте index.html именно из неё. Для обновления хостинга перенесите ВСЕ файлы из архива, включая index.html, app-rpm-v34.js, styles-rpm-v34.css, assets и vendor. Старые app.js и styles.css этой версией не используются.
Папка vendor необходима: в ней находятся шрифты и библиотеки экспорта.

Ордер на обыск использует компактную компоновку А4. Большие объёмы дополнительного текста продолжаются на следующем листе без обрезки содержания.
Документы и черновик сохраняются в текущем браузере. Перенос истории доступен во вкладке «Мои документы».

РП-отыгровки находятся справа от документа, на узких экранах — под ним. Сценарий обновляется при изменении документа. Каждая команда /me или /do содержит до 200 символов; количество команд не ограничено. Копируйте команды по отдельности или кнопкой «Копировать следующую». «Весь сценарий» копирует команды отдельными строками. Текст каждой команды можно отредактировать. Последовательности из 6 и более заглавных букв становятся строчными. Лист центрируется в области просмотра; кнопка «По ширине» подбирает масштаб.

Штампы: Government, CPD, FBI, Больница и ВМС используют собственные изображения в едином стиле. В списке «Штамп» доступен пункт «Свой штамп по ссылке». Вставьте прямую ссылку на PNG, JPG, WebP или GIF и нажмите «Загрузить штамп». Хостинг должен разрешать загрузку изображений с других сайтов (CORS). После загрузки штамп хранится в документе и работает при повторном открытии и экспорте без обращения к исходной ссылке. Для прозрачного фона используйте PNG.

В обстоятельствах каждого ордера есть список шаблонов. Выбранный текст можно редактировать. Название органа в начале шаблона обновляется при изменении организации в блоке «Выдача ордера», остальная часть текста сохраняется. «Структура» в постановлении обозначает исполнителя ордера.
Предпросмотр штампа в настройках убран; штамп отображается только на самом документе. Стиль документа и штамп выбираются отдельно.

Категория «Больница»: психотерапевтический осмотр, медицинский осмотр, заключение хирургической операции, свидетельство о смерти. В каждой форме есть быстрое заполнение с редактируемыми вариантами. Поля в квадратных скобках нужно заменить результатами конкретного случая. Имя врача в полях подставляется в подпись. В свидетельство о смерти можно загрузить фотографию, она сохраняется вместе с документом.

Отмена: кнопка ↶ или Ctrl+Z. Возврат: ↷ или Ctrl+Shift+Z. На macOS используются Cmd+Z и Cmd+Shift+Z. История правок работает в текущей вкладке, включает поля, разделы, подписи, изображения и ручные изменения РП-команд. После отмены новая правка заменяет ветку возврата.
Перенос одного документа: меню «Файл» → «Скачать документ». Перенесите файл .rpmdoc на другой ПК, откройте эту версию RPM Docs и выберите «Файл» → «Открыть документ». В файл включаются текст, поля заполнения, даты, подписи, выбранный штамп, эмблема и фотография. Открытие документа не заменяет список «Мои документы». Текущий документ можно восстановить кнопкой отмены.
РП-передача оставлена только в договорах и медицинских справках об осмотре. Стиль RPM Hospital называется «Медицинский v2».
